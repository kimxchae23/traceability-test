# Traceability Test

Word 문서의 개정 전·후 내용을 장절 단위로 비교하고, 변경사항을 Excel 추적성 분석표에 반영하는 Python 도구입니다.

SRS, DS, SDD 문서의 변경 내용을 확인하고 관련 추적성 항목에 재검토 표시를 남기는 작업을 지원합니다.

## 주요 기능

- Word 문서에서 장절 번호와 본문을 추출하여 비교합니다.
- 변경사항을 `동일`, `수정`, `이동`, `이동+수정`, `추가`, `삭제`, `변경확인필요`로 분류합니다.
- 파일명에서 요건단계·설계단계 추적성 분석표를 자동으로 찾습니다.
- 정방향·역방향 시트의 문서별 Contents 열을 갱신하고 Comment 열에 검토 의견을 기록합니다.
- 원본 Excel을 유지하고 별도의 `_Rev01.xlsx` 파일로 저장합니다. 같은 이름의 결과 파일이 있으면 덮어씁니다.

## 파일 구성

| 파일 | 설명 |
| --- | --- |
| `compare.py` | 문서 비교 및 Excel 갱신 프로그램 |
| `old_srs.docx` | 개정 전 Word 문서 |
| `new_srs.docx` | 개정 후 Word 문서 |
| `부록c. 요건단계 추적성 분석표 test.xlsx` | 입력 추적성 분석표 예제 |
| `부록c. 요건단계 추적성 분석표 test_Rev01.xlsx` | 결과 파일 예제 |

## 설치 및 실행

Python 3 환경에서 다음 패키지를 설치합니다.

```bash
python -m pip install openpyxl python-docx
```

`compare.py`와 입력 파일들이 있는 폴더에서 실행합니다.

```bash
python compare.py
```

실행하면 터미널에 장절별 비교 결과와 Excel 반영 내역이 출력되고, 입력 Excel 파일명에 `_Rev01`을 붙인 결과 파일이 생성됩니다.

예: `부록c. 요건단계 추적성 분석표 test.xlsx` → `부록c. 요건단계 추적성 분석표 test_Rev01.xlsx`

## 입력 파일과 설정

### Word 문서

기본 입력 파일은 `old_srs.docx`, `new_srs.docx`입니다. 다른 문서를 비교하려면 `compare.py` 상단의 설정을 변경합니다.

```python
OLD_WORD = "old_srs.docx"
NEW_WORD = "new_srs.docx"
DOCUMENT_TYPE = "SRS"  # SRS, DS, SDD
```

장절 번호는 다음처럼 문단의 실제 텍스트에 포함되어 있어야 합니다.

```text
5.1 입력
입력에 관한 요구사항입니다.

5.1.1 입력 처리
입력 처리에 관한 요구사항입니다.
```

`5.1`, `5.1.1`처럼 점으로 구분한 숫자 뒤에 공백이 있는 형식을 인식합니다. `5` 같은 단일 번호, Word 자동 번호 매기기로만 표시되는 번호, 표 안의 텍스트는 현재 파싱 대상에 포함되지 않습니다.

### Excel 추적성 분석표

실행 폴더에 아래 조건을 만족하는 입력 파일이 **정확히 하나** 있어야 합니다.

- 확장자: `.xlsx` — 결과 파일명 생성을 위해 소문자 확장자를 사용합니다.
- 파일명에 `요건단계 추적성 분석표` 또는 `설계단계 추적성 분석표` 포함
- 파일명이 `~$`로 시작하는 임시 파일과 이름에 `_rev`가 포함된 파일은 검색에서 제외

처음 두 시트만 처리하며, 시트명에 `정방향` 또는 `역방향`이 있으면 해당 방향을 사용합니다. 이름에 방향이 없으면 첫 번째 시트는 정방향, 두 번째 시트는 역방향으로 처리합니다.

데이터는 3행부터 읽고, Contents는 C열·F열, 검토 의견은 G열을 사용합니다. Contents 셀은 장절 번호로 시작해야 합니다.

| 단계 | 방향 | C열 Contents | F열 Contents |
| --- | --- | --- | --- |
| 요건단계 | 정방향 | DS | SRS |
| 요건단계 | 역방향 | SRS | DS |
| 설계단계 | 정방향 | SRS | SDD |
| 설계단계 | 역방향 | SDD | SRS |

`DOCUMENT_TYPE`에는 해당 단계에서 사용하는 문서 종류를 지정해야 합니다. 요건단계는 `DS`·`SRS`, 설계단계는 `SRS`·`SDD`를 지원합니다.

## 변경사항 반영 방식

| 비교 결과 | Excel 처리 |
| --- | --- |
| 동일 | 변경하지 않음 |
| 수정 | 해당 Contents 갱신, `재검토 필요` 표시 |
| 이동 | 해당 Contents 갱신, `장절 이동 - 재검토 필요` 표시 |
| 이동+수정 | 해당 Contents 갱신, `장절 이동 및 수정 - 재검토 필요` 표시 |
| 삭제 | 기존 Contents 유지, 문서 삭제 및 추적성 재검토 의견 표시 |
| 변경확인필요 | 기존 Contents 유지, `변경 관계 확인 필요` 표시 |
| 추가 | 터미널에 출력하며 Excel 행은 자동으로 추가하지 않음 |

개정 전 장절 번호를 기준으로 기존 Excel 행을 찾습니다. 같은 장절이 여러 행에 연결되어 있으면 해당 행들을 모두 처리합니다. 매칭되는 행이 없으면 터미널에 안내하고 건너뜁니다.

## 확인 사항

- 비교 결과는 텍스트 유사도와 장절 순서를 이용한 추정입니다. 생성된 결과와 재검토 의견을 확인해 주세요.
- 신규 장절의 추적성 연결은 결과 파일에서 직접 작성해야 합니다.
- Excel 양식의 열 위치나 데이터 시작 행이 다르면 코드의 매핑과 설정을 조정해야 합니다.
- 결과 저장 시 권한 오류가 발생하면 열려 있는 결과 Excel 파일을 닫고 다시 실행하세요.
